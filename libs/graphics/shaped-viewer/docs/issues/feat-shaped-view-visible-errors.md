# shaped-view shows the user why a file did not open

shaped-view is a windowed program, so what it logs reaches no console.
A double-clicked file that does not open, or imports with issues, leaves an empty studio background and says nothing.
The errors and warnings it logs today should reach the window: a line drawn over the view, or a message box on Windows.
