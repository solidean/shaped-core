# Query a capture as data: a CLI and an MCP server, JSON in and out

An agent asks what a frame did, for a pixel or a draw, and gets an answer it can act on, without screenshots of a GUI.
The repo_tools MCP server is the shape to follow: narrow questions, budgeted answers, a selector that points at the next question.
